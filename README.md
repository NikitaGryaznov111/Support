Support это веб-приложение, позволяющее пользователям:

Создавать, удалять, редактировать задачи
Добавлять задачи в проекты
Запускать и останавливать таймер
Сохранять потраченное на задачу время после перезагрузки страницы
Регистрироваться новым пользователям
Сохранять данные в базе данных

Фронтенд реализован на React , бэкенд — на Node.js + Express , используется MongoDB.
В настоящее время проект находится на этапе доработки, нужно структурировать некоторые части кода, сделать его более читаемым и разбить на составные части. Доработать логику на бэкенде и покрыть код тестами. Реализовать общую статистику по выполненным задачам и проектам.

  Проект разделен на две части:
  1. папка frontend
  2. папка server
   
  Для установки необходимо:
  1. Склонировать репозиторий, перейти в каждую из указанных выше папок и установить все зависимости
  2. Создать в корне папки server файл .env:
      PORT = 5000
      CLIENT_URL = 'http://localhost:5173'
      DB_URL ='mongodb+srv://usersAuth:usersAuth@cluster0.dapnm.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0'
      JWT_ACCESS_TOKEN ='jwt-access-secret-ket'
     
  4. Находясь в папке frontend выполнить команду npm run dev
  5. Находясь в папке server выполнить команду npm run dev
